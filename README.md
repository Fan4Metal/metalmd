# qmarkdown

Быстрый нативный просмотрщик Markdown на Rust. Это переписанная на Rust часть
[Markpad](https://github.com/sftwrdotdev/Markpad), отвечающая за просмотр.
Редактора нет, главная цель — как можно быстрее показать документ.

Markpad построен на Tauri и SvelteKit: при открытии файла он поднимает WebView2 и
загружает JS-бандл с Monaco, KaTeX и Mermaid. qmarkdown рисует документ сам через
[egui](https://github.com/emilk/egui) и OpenGL, без браузерного движка.

## Скорость открытия

Время от создания процесса до кадра с документом. Измерено в release-сборке на
Windows 10, i7-12700K, RTX 4070 Ti, 2560×1440 при 125%. Медиана 10 запусков с
тёплым кэшем ОС.

| Документ | Документ отрисован | Следующий кадр (первый уже на экране) |
|---|---|---|
| `samples/markdown-syntax.md`, 27 КБ | 168 мс | 219 мс |
| 4,9 МБ Markdown | 208 мс | 263 мс |

Около 130 мс из этого времени уходит на создание окна и контекста OpenGL в драйвере
видеокарты. Чтение и разбор документа идут параллельно с этим, а вёрстка первого
экрана добавляет 10–50 мс даже для мегабайтных файлов. Повторный запуск с другим файлом не
создаёт второе окно: путь передаётся уже открытому окну, и файл открывается в
новой вкладке.

Почему так быстро:

- Файлы из командной строки читаются и разбираются в фоновых потоках сразу после
  старта процесса, пока создаётся окно.
- Документ разбирается один раз в готовую модель блоков. Каждый кадр размечаются
  только видимые блоки, высоты остальных досчитываются понемногу в фоне.
- Подсветка синтаксиса, наблюдение за файлом и шрифты для китайского, японского и
  корейского загружаются после первого кадра и только когда нужны.
- Рендерер OpenGL (glow). На той же машине wgpu с DirectX 12 создаёт контекст
  ~240 мс, а с Vulkan ~290 мс, против ~130 мс у OpenGL.

Замер на своей машине:

```
qmarkdown.exe --bench timings.json path\to\file.md
```

Программа откроет файл, запишет отметки времени в миллисекундах с момента создания
процесса и закроется.

## Возможности

- GitHub-совместимый Markdown на [comrak](https://github.com/kivikakk/comrak):
  таблицы, списки задач, зачёркивание, автоссылки, сноски, alerts вида `> [!NOTE]`
  и front matter.
- Расширения Markpad: `==выделение==`, `++вставка++`, `^[встроенная сноска]`,
  списки определений, вики-ссылки `[[Файл#Заголовок|текст]]`, вставки
  `![[картинка.png|300x200]]`, якоря `^block-id`. Одиночный перевод строки
  считается разрывом строки.
- Подсветка кода для ~200 языков через syntect и two-face.
- Картинки: PNG, JPEG, GIF, WebP, SVG, BMP, локальные и по http(s).
- Подмножество HTML, частое в README: `<img>`, `<a>`, `<br>`, `<p align="center">`,
  `<b>`, `<kbd>`, `<sub>`, `<sup>`, `<mark>`, `<details>`.
- Оглавление с подсветкой текущего раздела и переходом по клику.
- Вкладки, недавние файлы, перетаскивание файлов в окно.
- Поиск по документу, автоперезагрузка при изменении файла с сохранением позиции.
- Светлая, тёмная и системная тема, масштаб.
- Файлы в UTF-8, UTF-16 и устаревших кодировках (Windows-1251, GBK, Shift_JIS и др.)
  определяются автоматически.

Не поддерживается: редактирование, рендеринг формул KaTeX и диаграмм Mermaid (они
показываются как код), видео, аудио и превью YouTube, дополнительные виды alerts
из Markpad (`[!TODO]` и т. п.) и сворачиваемые alerts, картинки `data:`, а также
HTML за пределами перечисленного подмножества.

## Горячие клавиши

| Клавиши | Действие |
|---|---|
| Ctrl+O | Открыть файл |
| Ctrl+W, средняя кнопка мыши на вкладке | Закрыть вкладку |
| Ctrl+Tab, Ctrl+Shift+Tab | Следующая и предыдущая вкладка |
| Ctrl+F | Поиск |
| Enter, F3 / Shift+Enter, Shift+F3 | Следующее и предыдущее совпадение |
| Esc | Закрыть поиск |
| Ctrl+Shift+O | Показать или скрыть оглавление |
| F5, Ctrl+R | Перечитать файл |
| Alt+←, кнопка «назад» мыши | Вернуться после перехода по ссылке |
| Ctrl+= / Ctrl+− / Ctrl+0 | Масштаб |
| PageUp, PageDown, пробел, Home, End, стрелки | Прокрутка |

Ссылки на другие `.md` открываются в новой вкладке, якоря `#заголовок` прокручивают
документ, остальные ссылки открываются в системе.

## Сборка

Нужен Rust 1.95 или новее (этого требует egui 0.36).

```
cargo build --release
```

Готовый файл: `target\release\qmarkdown.exe`. Он один и не требует установки.

Чтобы открывать `.md` двойным щелчком, в контекстном меню файла выберите
«Открыть с помощью» → «Выбрать другое приложение» → `qmarkdown.exe` →
«Всегда использовать это приложение».

Запуск с параметром `--new-instance` открывает отдельное окно вместо передачи файла
уже запущенному.

Настройки и список недавних файлов хранятся в
`%APPDATA%\qmarkdown\config\settings.json`.

## Устройство

```
src/
  main.rs              аргументы, передача файлов запущенному окну, старт загрузки, eframe
  app.rs               вкладки, сообщения от фоновых потоков, ссылки, клавиши, панели
  bench.rs             --bench: отметки времени запуска
  fs_text.rs           чтение файла и определение кодировки (из Markpad)
  settings.rs          настройки и недавние файлы
  single_instance.rs   один процесс на пользователя: именованный канал / локальный сокет
  watcher.rs           слежение за файлами (notify)
  style.rs             цвета, шрифты, оформление egui
  markdown/
    preprocess.rs      вики-ссылки, вставки, block id, опции comrak (из Markpad)
    document.rs        AST comrak → модель блоков со стилизованным текстом
    html.rs            токенизатор HTML для README-подмножества
    highlight.rs       подсветка кода в фоновом потоке
  ui/
    viewer.rs          отрисовка документа с виртуализацией
    toc.rs             оглавление
    find.rs            поиск
    home.rs            стартовая страница
```

Тесты: `cargo test`. Тесты разбора портированы из Markpad.
