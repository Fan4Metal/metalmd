<p align="center"><a href="README.md">English</a> | <b>Русский</b></p>

MetalMD показывает Markdown-документ примерно через 0,2 с после двойного щелчка. Редактировать документы он не умеет: единственное изменение, которое он вносит в файл, — отметка пункта списка задач. Это переписанная на Rust часть [Markpad](https://github.com/sftwrdotdev/Markpad), отвечающая за просмотр. Markpad построен на Tauri и SvelteKit: при запуске он поднимает WebView2 и загружает JS-бандл с Monaco, KaTeX и Mermaid. MetalMD рисует документ сам через [egui](https://github.com/emilk/egui) и OpenGL, без браузерного движка. Файл открывают в любимом редакторе, а MetalMD обновляет вид при каждом сохранении.

![MetalMD показывает документ: слева оглавление, справа выноска, список задач, таблица и блок кода с подсветкой](images/screenshot.png)

*Снимок экрана версии 0.2.0.*

## Возможности

- **Скорость**: документ появляется примерно через 0,2 с после запуска, будь то заметка на 27 КБ или лог на 5 МБ (см. [Скорость запуска](#скорость-запуска)).
- **Markdown в стиле GitHub** на [comrak](https://github.com/kivikakk/comrak): таблицы, списки задач, зачёркивание, автоссылки, сноски, выноски `> [!NOTE]` и front matter.
- **Синтаксис Obsidian и Markpad**: вики-ссылки `[[Заметка#Заголовок|текст]]`, вставки `![[картинка.png|300x200]]`, якоря `^block-id`, `==выделение==`, `++вставка++`, `^[встроенные сноски]` и списки определений. Одиночный перевод строки — это разрыв строки (см. [Поддержка Markdown](#поддержка-markdown)).
- **Подсветка кода** примерно для 200 языков, цвета следуют светлой или тёмной теме.
- **Формулы**: `$…$` и `$$…$$` набираются так же, как в KaTeX, с помощью [RaTeX](https://github.com/erweixin/RaTeX) — порта KaTeX на Rust.
- **Цветные эмодзи** системным шрифтом эмодзи (Segoe UI Emoji).
- **Диаграммы Mermaid** в блоках ```` ```mermaid ```` (блок-схемы, диаграммы последовательности, классов, состояний, ER, круговые, Ганта и другие) рисует [mermaid-svg](https://github.com/xmiksay/mermaid) в светлой или тёмной теме Mermaid.
- **HTML как в README**: центрированные блоки `<p align="center">`, `<img>` с размером, `<kbd>`, `<details>` и другие теги, частые в README.
- **Шрифты и размер текста**: кнопка Aa открывает панель, где шрифт текста, шрифт кода и размер текста выбираются из установленных в системе шрифтов. Изменения применяются сразу. Вариативные шрифты получают полужирное и курсивное начертания из своих осей, а семейство без курсива наклоняется.
- **Оглавление**: текущий раздел подсвечивается, щелчок переходит к заголовку. Оно стоит слева или справа: выберите правым щелчком по его кнопке или по панели.
- **Вкладки**: ссылки на другие `.md` открываются в новых вкладках. Недавние файлы показаны на стартовой странице, файлы можно перетащить в окно. Вкладка, вытянутая за пределы окна, получает собственное окно, вкладка, перетащенная в другое окно, переходит в него, а перетаскивание вдоль полосы меняет их порядок.
- **Автообновление**: изменённый на диске файл перечитывается, позиция прокрутки сохраняется.
- **Отметка пунктов списка задач**: щелчок по флажку переключает `- [ ]` и `- [x]` в самом файле. Меняется только этот символ, кодировка и концы строк остаются прежними.
- **Поиск** по документу через `Ctrl+F`. Текст можно выделить сразу в нескольких абзацах и скопировать.
- **Светлая, тёмная или системная тема** и масштаб.
- **Английский или русский интерфейс**: язык берётся из Windows, его можно сменить в окне «О программе» (`F1`).
- **Любая кодировка**: UTF-8, UTF-16 и устаревшие кодовые страницы (Windows-1251, GBK, Shift_JIS и другие) определяются автоматически.
- **Одно окно**: файл, открытый при запущенном MetalMD, попадает в новую вкладку уже открытого окна.
- **Портативность**: [портативный архив](#установка) хранит настройки рядом с программой.

## Поддержка Markdown

| Синтаксис | Пример |
|---|---|
| CommonMark | `**жирный**`, `*курсив*`, `` `код` ``, заголовки, списки, цитаты, линии, ссылки, картинки |
| Расширения GitHub | таблицы, списки задач `- [x]`, `~~зачёркивание~~`, голые URL, сноски `[^1]`, выноски `> [!NOTE]` |
| Obsidian | вики-ссылки `[[Заметка#Заголовок\|текст]]`, вставки `![[картинка.png\|300x200]]`, якоря `^block-id` |
| Другие расширения | `==выделение==`, `++вставка++`, `^[встроенная сноска]`, списки определений, YAML front matter |
| Формулы | `$E = mc^2$` в строке, `$$ … $$` отдельным блоком, LaTeX в объёме [KaTeX](https://katex.org/docs/supported) |
| Диаграммы | блоки ```` ```mermaid ````: виды диаграмм [mermaid-svg](https://github.com/xmiksay/mermaid) |
| Блоки кода | подсветка через [syntect](https://github.com/trishume/syntect) и грамматики [two-face](https://github.com/CosmicHorrorDev/two-face) |
| Картинки | PNG, JPEG, GIF, WebP, SVG, BMP и ICO, локальные и по http(s); анимированные GIF, WebP и APNG проигрываются; у SVG-значков виден текст |
| HTML | `<img>`, `<a>`, `<br>`, `<p align="center">`, `<b>`, `<i>`, `<kbd>`, `<sub>`, `<sup>`, `<mark>`, `<details>` (всегда раскрыт) |

**Не поддерживаются**:

- видео, аудио и превью YouTube: не показываются;
- дополнительные виды выносок из Markpad (`[!TODO]` и другие), сворачиваемые выноски и сворачивание `<details>`;
- картинки `data:`;
- HTML за пределами перечисленных тегов;
- цветные флаги: в Segoe UI Emoji флагов нет, поэтому 🇷🇺 показывается буквами RU, как в браузерах на Windows.

## Установка

Инсталлятор и портативный архив выложены на странице [Releases](https://github.com/Fan4Metal/metalmd/releases).

Инсталлятору `MetalMD_<версия>_Setup.exe` не нужны права администратора: программа ставится в `%LOCALAPPDATA%\Programs\MetalMD`. Пункт «Зарегистрировать MetalMD для файлов Markdown» включён по умолчанию (см. [Ассоциации файлов](#ассоциации-файлов)). Если он включён, последняя страница инсталлятора предлагает открыть параметры Windows, где MetalMD можно выбрать программой по умолчанию. При удалении регистрация снимается.

Портативный архив `MetalMD_<версия>_portable.zip` содержит программу в папке `MetalMD` и работает без установки. В нём также лежит пустой файл `metalmd.json`. Пока этот файл находится рядом с `metalmd.exe` и в папку можно писать, настройки и недавние файлы хранятся в нём, поэтому программу можно носить на флешке. Без этого файла они хранятся в `%APPDATA%\MetalMD\config\settings.json`, как у установленной программы. Где лежат настройки, видно в окне «О программе».

## Горячие клавиши

| Клавиши | Действие |
|---|---|
| `Ctrl+O` | Открыть файл |
| `Ctrl+W`, средняя кнопка мыши на вкладке | Закрыть вкладку |
| `Ctrl+Tab`, `Ctrl+Shift+Tab` (`Ctrl+PageDown`, `Ctrl+PageUp`) | Следующая и предыдущая вкладка |
| `Ctrl+F` | Поиск |
| `Enter`, `F3` / `Shift+Enter`, `Shift+F3` | Следующее и предыдущее совпадение |
| `Esc` | Закрыть поиск |
| `Ctrl+Shift+O` | Показать или скрыть оглавление |
| `F5`, `Ctrl+R` | Перечитать файл |
| `Alt+←`, кнопка «Назад» мыши | Вернуться после перехода по ссылке |
| `Ctrl+=` / `Ctrl+−` / `Ctrl+0`, `Ctrl`+колесо | Увеличить, уменьшить, сбросить масштаб |
| `PageUp`, `PageDown`, пробел / `Shift+пробел`, стрелки | Прокрутка |
| `Home`, `End` (`Ctrl+Home`, `Ctrl+End`) | В начало или в конец |
| `F1` | О программе |

Мышью: у блока кода под указателем появляется кнопка «Копировать», а контекстное меню формулы `$$` или диаграммы копирует исходный текст («Копировать TeX», «Копировать исходный код Mermaid»); щелчок по масштабу рядом с кнопками панели сбрасывает его; правый щелчок по кнопке или панели оглавления выбирает его сторону; перетаскивание вкладки за заголовок переставляет её в полосе, переносит в другое окно или выносит в новое, то же делает её контекстное меню, где также можно закрыть другие вкладки.

## Использование

```
metalmd.exe [ФАЙЛ...] [--new-instance]
```

Каждый файл открывается во вкладке. Если MetalMD уже запущен, файлы получает открытое окно и выходит на передний план. С `--new-instance` открывается отдельное окно.

Ссылки на другие Markdown-файлы (`.md`, `.markdown`, `.mdown`, `.mkd`, `.txt`) открываются в новой вкладке на заголовке или блоке, указанном после `#`. Ссылки `#якорь` прокручивают документ. Остальные ссылки открываются в программе по умолчанию.

Между запусками сохраняются тема, масштаб, язык интерфейса, шрифты и размер текста, видимость и сторона оглавления, положение и размер окна и девять последних файлов.

Программа не обращается к сети, кроме загрузки картинок, на которые документ ссылается по http(s).

## Ассоциации файлов

Пункт инсталлятора «Зарегистрировать MetalMD для файлов Markdown» регистрирует `.md`, `.markdown`, `.mdown` и `.mkd` для текущего пользователя. После этого MetalMD появляется в меню «Открыть с помощью» и в «Параметры» → «Приложения по умолчанию». Программу по умолчанию Windows разрешает выбрать только самому пользователю. Для этого инсталлятор предлагает открыть параметры, или MetalMD можно выбрать при первом открытии Markdown-файла.

Без инсталлятора: в контекстном меню `.md`-файла выберите «Открыть с помощью» → «Выбрать другое приложение» → `metalmd.exe` → «Всегда использовать это приложение».

## Скорость запуска

В таблице — время от создания процесса до кадра, на котором виден документ. Замер сделан на release-сборке в Windows 10 (i7-12700K, RTX 4070 Ti, 2560×1440, масштаб 125%): медиана 10 запусков с тёплым кэшем ОС.

| Документ | Документ отрисован | Следующий кадр |
|---|---|---|
| `samples/markdown-syntax.md`, 27 КБ | 168 мс | 219 мс |
| 4,9 МБ Markdown | 208 мс | 263 мс |

Около 130 мс из этого времени драйвер видеокарты создаёт окно и контекст OpenGL. Чтение и разбор документа идут параллельно с этим, а вёрстка первого экрана добавляет 10–50 мс даже для файлов в несколько мегабайт. За счёт чего такая скорость:

- Файлы из командной строки читаются и разбираются в фоновых потоках сразу после старта процесса, пока создаётся окно.
- Документ разбирается один раз в готовую модель блоков. В каждом кадре размечаются только видимые блоки, высоты остальных досчитываются понемногу.
- Подсветка синтаксиса, слежение за файлом и шрифты для китайского, японского и корейского загружаются после первого кадра и только когда нужны.
- Рендерер — OpenGL (glow). На той же машине wgpu создаёт контекст за ~240 мс с DirectX 12 и за ~290 мс с Vulkan, а OpenGL — за ~130 мс.

Замер на своей машине:

```
metalmd.exe --bench timings.json путь\к\файлу.md
```

Программа откроет файл, запишет отметки времени в миллисекундах с момента создания процесса и закроется.

## Сборка

Нужны Windows 10 или новее, стабильный Rust 1.95 или новее с тулчейном MSVC и Visual Studio 2022 Build Tools. Для запуска `build.py` нужен ещё [uv](https://docs.astral.sh/uv/).

```
uv run build.py          # target\release\metalmd.exe
cargo test
```

`build.py` сначала закрывает `metalmd.exe`, запущенный из папки `target` проекта, иначе файл занят. Затем он запускает `cargo build --release`, дополнительные аргументы передаются cargo. Единственную зависимость, `psutil`, ставит uv. Если MetalMD не запущен, подойдёт и обычный `cargo build --release`. C-рантайм вшит в exe (`.cargo/config.toml`), поэтому программе не нужно ничего, кроме самой Windows.

## Инсталлятор и релиз

Скрипт релиза собирает программу, инсталлятор и портативный архив. Для него нужен [Inno Setup 6](https://jrsoftware.org/isinfo.php).

```
python tools/make_release.py              # тесты, release-сборка, инсталлятор, архив
python tools/make_release.py --no-tests   # то же без cargo test
python tools/make_release.py --install    # затем тихая установка поверх установленной копии
```

Файлы попадают в `dist`, версия берётся из `Cargo.toml`. Как и `build.py`, скрипт сначала закрывает `metalmd.exe`, запущенный из `target\release`. Скрипт инсталлятора — `tools/setup.iss`. Иконку для инсталлятора записывает `metalmd.exe --export-icon <file.ico>`.

Релизы на GitHub собирает workflow **Release** (`.github/workflows/release.yml`). Обновите версию в `Cargo.toml`, закоммитьте её и отправьте тег с той же версией. Workflow опубликует релиз с инсталлятором и портативным архивом:

```
git tag v0.2.0
git push origin v0.2.0
```

Ручной запуск workflow (Actions → Release → Run workflow) только собирает файлы и прикладывает их к запуску, без релиза.

## На чём сделано

MetalMD построен на открытых проектах:

- [Markpad](https://github.com/sftwrdotdev/Markpad): диалект Markdown, предобработка, определение кодировки;
- [egui / eframe](https://github.com/emilk/egui): интерфейс и окно;
- [comrak](https://github.com/kivikakk/comrak): разбор Markdown;
- [syntect](https://github.com/trishume/syntect) и [two-face](https://github.com/CosmicHorrorDev/two-face): подсветка кода;
- [RaTeX](https://github.com/erweixin/RaTeX) и шрифты [KaTeX](https://katex.org): формулы;
- [mermaid-svg](https://github.com/xmiksay/mermaid): диаграммы Mermaid;
- [resvg](https://github.com/linebender/resvg): отрисовка формул, диаграмм, эмодзи и SVG-картинок;
- [notify](https://github.com/notify-rs/notify): слежение за изменениями файлов;
- [Inno Setup](https://jrsoftware.org/isinfo.php): инсталлятор.
